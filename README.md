# Casmara Türkiye

Casmara Türkiye web sitesi — Vite + React + TypeScript, GSAP ve Lenis animasyonları.

- `npm run dev` — geliştirme sunucusu
- `npm run build` — `dist/` üretir ve her sayfa için klasör kopyalar (GitHub Pages derin linkleri için)
- İçerik: `src/data/content.json` (site haritası dokümanından üretildi)
- Görseller: `public/img/*.webp`

`main` dalına her gönderimde `.github/workflows/pages.yml` siteyi GitHub Pages'e yayınlar.
Özel alan adı için `public/CNAME` dosyası eklemek yeterli.
